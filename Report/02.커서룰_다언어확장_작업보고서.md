# MagicSquare 커서룰 다국어 확장 작업 보고서

작성일: 2026-05-18

## 1. 작업 개요

기존 `.cursor/rules` 폴더에 작성되어 있던 Python 대상 커서룰을 참조하여
MagicSquare 프로젝트의 C++ 및 Java 언어용 커서룰을 추가 작성했습니다.

작업 목적은 Python에서 정의한 프로젝트 원칙, ECB 아키텍처, TDD 규칙, 테스트
규칙, 금지 패턴을 C++와 Java 개발 환경에서도 동일한 방향으로 적용할 수 있도록
언어별 규칙 파일로 분리하는 것입니다.

기준이 된 기존 규칙 파일은 다음과 같습니다.

```text
  magicsquare-python-code-style.mdc

```

위 규칙들은 MagicSquare 프로젝트의 핵심 개발 원칙을 담고 있습니다.

- TDD Red-Green-Refactor 흐름 준수
- 테스트 우선 확인 및 관련 테스트 작성
- 최소 80% 커버리지 기준
- 금지 패턴 발생 시 대안 사용
- AI 에이전트의 코드 작성 전·중·후 행동 기준

## 5. ECB 규칙 적용 방식

C++와 Java 모두 기존 Python 규칙의 ECB 구조를 유지했습니다.

- `boundary`: CLI, API, UI 등 외부 입출력 담당
- `control`: use case, application service, workflow 조합 담당
- `entity`: 도메인 데이터, 불변식, 순수 도메인 규칙 담당

의존성 방향은 두 언어 모두 동일하게 유지했습니다.

```text
boundary -> control -> entity
control -> entity
```

`entity`가 `control` 또는 `boundary`에 의존하는 것은 금지했습니다.
`control`이 구체적인 `boundary` 구현에 직접 의존하는 것도 금지하고,
필요한 경우 인터페이스나 DTO, DI를 통해 분리하도록 규정했습니다.

## 6. TDD 및 테스트 규칙

C++와 Java 모두 기존 TDD 흐름을 유지했습니다.

- Red: 실패하는 테스트를 먼저 작성하고 실패 원인을 확인
- Green: 테스트 통과에 필요한 최소 코드만 작성
- Refactor: 기능 변경 없이 구조와 가독성 개선

언어별 테스트 프레임워크는 다음과 같이 지정했습니다.

- C++: GoogleTest
- Java: JUnit 5

테스트 패턴은 공통으로 AAA(Arrange-Act-Assert)를 사용하며, 커버리지 기준은
최소 80%로 유지했습니다.
